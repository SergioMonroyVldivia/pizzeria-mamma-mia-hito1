# Pizzería Mamma Mía - Hito 1

Proyecto desarrollado en React con Vite y Bootstrap como parte del primer hito de la aplicación web para la Pizzería Mamma Mía.

## Componentes creados
- **Navbar:** Barra de navegación con botones condicionales según estado de sesión y total formateado.
- **Header:** Banner principal de bienvenida.
- **Home:** Vista principal que agrupa el catálogo de pizzas.
- **CardPizza:** Tarjetas reutilizables con imagen, ingredientes y precio dinámico mediante props.
- **Footer:** Pie de página institucional.

## Cómo ejecutar el proyecto localmente
1. Clonar el repositorio.
2. Instalar dependencias con `npm install`.
3. Levantar el entorno de desarrollo con `npm run dev`.
